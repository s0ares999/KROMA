# Fluxo de desenvolvimento

- Antes de alterar o site para desenvolver uma funcionalidade, criar e usar uma branch dedicada a essa funcionalidade.
- Usar nomes descritivos com o prefixo `codex/`, por exemplo `codex/contact-form` ou `codex/portfolio-projects`.
- Continuar na mesma branch enquanto se trabalha na mesma funcionalidade; criar outra branch quando se iniciar uma funcionalidade diferente.
- Não desenvolver funcionalidades diretamente na branch principal.
